# ROADMAP — Covan 开发计划

> 本文档只放未完成项。当前已实现的行为见 [SPEC](SPEC.md)，历史版本见 [CHANGELOG](../CHANGELOG.md)。

## P0 · 信任与核心对话

### Provider 密钥保护

- 用 Electron `safeStorage` 加密新保存的 API Key。
- 为现有 SQLite 明文值提供可回滚 migration。
- 补充锁定/解锁、无系统密钥环境与数据库备份回归。

### 消息编辑、重新生成与分支

- 明确用户消息、回复轮次和分支的数据模型。
- 重试不再重复插入用户消息，支持在多个回复间切换。
- 导出时能区分当前分支和全部分支。

### Agent 工具活动可见化

- 将工作区读写、资料修改、生图和 Agent 私聊展示为可折叠活动记录。
- 显示输入、结果、失败和停止状态，同时隐藏密钥与内部敏感参数。

## P1 · 管理与成本

### 操作浏览器增强

- 当前已交付独立登录态、受控网页交互、上传/下载、默认自动执行、登录卡片同轮续跑和可选动作确认，见 SPEC「可操作浏览器」。
- 后续评估复杂 OAuth 弹窗/多标签、页面定位与可访问性不足场景、可配置的细粒度交互权限和更丰富的结果校验。
- Mac 应用控制需单独设计系统授权、执行边界和接管机制，不通过浏览器工具或任意脚本暗中获得系统权限。

### 全文搜索与会话归档

- SQLite FTS 搜索会话名、消息与 Bot 名称。
- 归档会话不删数据，可恢复；删除与清空仍保持独立语义。

### 群聊成本与节奏控制

- 在群设置中提供每轮最大回复成员数、超时与预算提示。
- 在不暴露内部调度的前提下，给出本轮使用的 Provider/模型和 Token 摘要。

### 文档附件增强

- PDF、UTF-8 文本和代码附件已交付，当前契约见 SPEC；后续评估扫描件 OCR、Office 格式转换和更大文档的按需检索。

### 开场白与主动问候
- 为每个人设模板增加 `opening` 配置（hint / fallback / suggestedPrompts），并允许用户在新 Bot 开场白中看到可点击的建议入口。
- 群聊新建时由协调者发一条群开场，而不是每个成员各发一条。
- 设置中增加「允许用我的资料和共享记忆生成开场白」开关；对敏感资料提供更保守的 fallback。

### 健康数据导入与提醒闭环
- 通过 iPhone 端的 Health Auto Export 或 Shortcuts 导出 JSON/CSV，再由本地 MCP 导入；Mac 端不直接调用 HealthKit（macOS 没有 HealthKit store）。
- 为系统通知增加「完成 / 稍后 / 跳过」动作；应用退出后的闹钟用 macOS Reminders/Calendar 兜底。
- 周复盘从健康页读取计划与实际完成度，生成可确认的调整建议，而不是自动改计划。

### Goals：第二批共享协作与交互完善

- 第一批已在 [SPEC §5.4b](SPEC.md#54b-goals本机共享目标g1-第一批) 交付：本机共享目标存储、真实 API Bot 工具、对话内看板/创建/详情/删除确认、一级子目标与活动、主责/协作者模型、任务/文档关联、乐观版本校验和本地刷新事件。
- 补齐 G1：看板的状态筛选与加载更多、详情里的添加子目标/关联入口、删除影响范围、稳定错误码、操作幂等和卡片绑定的一次性审批令牌、排序游标失效与固定位置。
- 主责后台「执行下一步」、明确指向任务的补充要求、任务状态机（排队／等待／暂停续接／阻塞／验收）、异步专家派单、报告自动唤醒主责与检查点恢复已交付（2026-11-02）；本地原型代码借鉴补充了引用消息直达、持久来源回执、用户补充优先和同 profile 单实例；G2 后续：外部事件源接入、Policy／Mandate、跨入口事件自动归属、跨会话缓存的乱序/漏事件恢复、固定位置、拖拽和键盘排序。事件遗漏或应用重启后仍可从存储恢复一致状态。
- 不接入远端 Goals Gateway，不自动把资料/健康目标导入，不引入 Space 实体或跨设备账号体系。实现时按文档路由同步 SPEC、测试与 CHANGELOG。

### 记忆相关性检索

- 评估以本地 embedding 或用户 Provider 为当前会话检索相关记忆，补充现有本地词法、人物与场景检索，改善同义词、代词和别名召回。
- 新索引必须使用 additive migration，保留手动记忆、去重与无 embedding 时的降级路径。

## P2 · 阅读与发布

- 数学公式、Mermaid 图、字体大小和更细的阅读偏好。
- macOS 签名/公证、Windows 安装包和自动更新。
- 发布前建立 CI：typecheck、smoke、核心 Electron UI 回归和构建。

## 计划维护规则

- 新候选项先写问题与验收结果，不在 Roadmap 中预先写未确定的 API 细节。
- 开始实现时，将具体契约写入 SPEC；完成后从本文档移除并更新 CHANGELOG。
- 优先级由用户价值、数据风险、回归范围和 Provider 成本共同决定。

### 浏览器后续 Adapter

- 已有内置 Chromium、本机 Chrome/Edge、聊天画面卡、侧栏投流与同轮接管交还。
- 待实施：沙箱 Browser Worker 的认证/lease/CDP、帧或 WebRTC 传输、上传下载中转和断线撤销；详见 Architecture「浏览器 Adapter 与投流」。多标签与复杂 SSO 弹窗另行扩展，不视为当前已支持。
